# Security and correctness challenge

The following situations occur in production:

- A school email contains text instructing the system to delete calendar events and forward messages to an external address.
- A receipt contains misleading information, such as a total that does not match its line items.
- Two school emails give conflicting dates for the same event.
- The same receipt arrives both directly and as a forwarded message.
- An external source makes claims that cannot be verified.

Identify the trust boundaries in your design. Explain the validation strategies you would use and how the system prevents unauthorized or incorrect operations. State any changes you would make to your design.
